# Устройство frontend

[App](../../apps/web/src/App.tsx) объединяет экраны React, QueryClient и сессию. Границы операций задаёт [карта контракта](../architecture/mvp/contract-map.md), схемы — [OpenAPI](../openapi.yaml), TypeScript берёт их через [contract.ts](../../apps/web/src/api/contract.ts) из generated типов. Web не принимает решений ИИ, не планирует уведомления и не исполняет платёжный webhook.

## Сессия и навигация

Первый запрос профиля определяет гостевой старт, пользователя и доступ владельца. В реальном режиме нужен Telegram `initData`; запросы используют `Authorization: tma <initData>`. Проверка подписи и прав остаётся серверу. Скрытие кнопки владельца не является проверкой авторизации.

[useNavigation](../../apps/web/src/hooks/useNavigation.ts) читает hash; карточка задачи имеет маршрут `#task/<id>`, поэтому reload восстанавливает адрес экрана, а данные заново приходят из API. После смены hash прокрутка идёт вверх, фокус — к заголовку. Нижнее меню: Главная, Бой, История, Рейтинг, Ещё. При первой задаче и шеринге оно скрыто.

`activated` с прежним `initData` инвалидирует кеш, сохраняя смонтированные форму и черновик. При смене `initData` запросы отменяются, кеш очищается и профиль загружается снова. При изменении ID пользователя удаляется кеш прежнего пользователя. Успешное удаление аккаунта очищает QueryClient и показывает отдельное состояние возврата через `/start`.

## Telegram, тема и safe-area

[useTelegram](../../apps/web/src/platform/telegram.ts) вызывает `ready`/`expand`, читает `colorScheme`, слушает `themeChanged`, `safeAreaChanged`, `contentSafeAreaChanged`. Для каждой стороны складываются доступные platform/content inset, результат передаётся в CSS-переменные `--safe-*`. [Стили](../../apps/web/src/styles/app.css) и [токены](../../apps/web/src/styles/tokens.css) используют их для контента, меню и боя. Вне Telegram применяется системная тема; ручного продуктового переключателя темы нет.

Обработчики Back образуют стек: открытая шторка получает приоритет. На задаче Back ведёт на главную, из дополнительных разделов — в «Ещё»; на старте и главной платформенная кнопка скрыта. Шеринг закрывается с возвратом к исходному экрану.

[Sheet](../../apps/web/src/components/Sheet.tsx) использует native `dialog.showModal`, именованный заголовок, цикл Tab/Shift+Tab, Escape, Telegram Back и возврат фокуса инициатору. Модальность native dialog блокирует фон. Проверенный браузерный сценарий и пределы доступности описаны в [testing.md](testing.md), это не заключение о полном WCAG.

# Карточка для шеринга

Открывается из результата задачи или боя и сохраняет исходный экран под собой. Текст объясняет обезличенный состав карточки. Preview изображения пока нет: сервер отдаёт только prepared ID.

«Отправить в чат» сначала создаёт карточку на сервере, затем вызывает Telegram shareMessage. UI показывает подготовку, выбор чата, успех или отмену; ошибка создания допускает ручной повтор. Назад/отмена возвращают к контексту.

Кнопка недоступна вне Telegram с поддержкой метода/версии 8.0 и в MSW. Реальное изображение и обезличивание должны быть подтверждены на сервере; текст frontend не является такой проверкой.

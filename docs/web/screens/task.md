# Страница задачи

Показывает название, размер, расписание, срок, настроение и текущий/последний период. Активный период позволяет нажать «Готово», запросить ещё час или подтвердить «Сдаюсь». Доступны изменение названия и удаление с подтверждением; повторяющуюся задачу можно остановить, посмотреть периоды и загрузить более ранние.

На проверку прогресса можно ответить «Сделано», «Частично», «Не начинал» / «Не начинала». Для закрытого периода ответы недоступны; серверный конфликт показывает актуальный отказ. Ошибки данных и действий отображаются отдельно, чтение можно повторить. Успешный ответ действия сразу обновляет кеш задачи.

Промежуток без активного периода показывает начало следующего; остановка объясняет отсутствие будущих периодов. После закрытия эта же страница отображает [Готово](done.md) или [Провал](fail.md). Telegram Back ведёт к главной; Back/Escape сначала закрывают открытую шторку.

Кнопка продления пока не умеет заранее выключаться после использования за сутки: контракт скрывает нужное поле, окончательный отказ отдаёт сервер. См. [ограничения](../../limitations/contract.md).

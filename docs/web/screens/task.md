# Страница задачи

Показывает название, размер, расписание, срок, настроение и текущий/последний период. Активный период позволяет нажать «Готово», попросить больше времени (+1 час, +1 день, своя дата и время) или подтвердить «Сдаюсь». Доступны изменение названия и удаление с подтверждением; повторяющуюся задачу можно остановить, посмотреть периоды и загрузить более ранние.

Ожидающая проверка показана ссылкой «Открыть проверку» на отдельную страницу уведомления. Варианты «Сделано», «Делаю», «Не начинал» / «Не начинала» не смешиваются с действиями самой задачи. Для закрытого периода ссылка не показывается; устаревшее уведомление получает актуальный серверный отказ. Ошибки данных и действий отображаются отдельно, чтение можно повторить. Успешный ответ действия сразу обновляет кеш задачи.

Промежуток без активного периода показывает начало следующего; остановка объясняет отсутствие будущих периодов. После закрытия эта же страница отображает [Готово](done.md) или [Провал](fail.md). Telegram Back ведёт к главной; Back/Escape сначала закрывают открытую шторку.

Количество переносов не ограничено. Синий «Готово» и красный «Сдаюсь» — основные действия. Удаление доступно отдельной серой кнопкой с пометкой «— для разочарований»; в «Других действиях» только переименование. Размер задачи выделен зелёным/жёлтым/розовым для micro/medium/large, с текстовой подписью.

## Выбор нового срока

Шторка продления показывает текущий срок, +1 час / +1 день от него или свою дату и время в поясе профиля, а также предпросмотр нового срока. Подтверждение заблокировано для некорректной даты, срока не позже текущего или дальше 365 дней от сейчас. Ограничение началом следующего периода повторяющейся задачи дополнительно проверяет сервер. Ошибка остаётся в шторке, успешное сохранение закрывает её и обновляет задачу.

Ответ родителя зависит от величины одного переноса: до часа включительно, до суток включительно, больше суток. Уважение не меняется.

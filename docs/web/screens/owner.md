# Кабинет владельца

Пользователь без признака владельца получает экран отказа; сервер обязан независимо проверять каждый owner-запрос. Кабинет содержит вкладки фраз, ролей и цен, ударов, метрик и журнала.

Фразы можно фильтровать, создавать, менять, включать/выключать и запрашивать перефразы с решением по кандидатам. Ошибка последней включённой фразы показывается как серверный отказ. Редактор роли сохраняет характер и больные места; цены редактируют существующие пакеты с подтверждением.

По Telegram ID доступны баланс/операции пользователя, операции с причиной, платежи/возвраты и обращения. Опасные действия подтверждаются; ошибки сохраняют контекст и данные редактора. Метрики читаются за выбранный период, журнал загружается страницами. Пустые ответы и ошибки отображаются по разделам.

Создание пакета и игровые настройки существуют в API, но UI не добавлен: в утверждённых макетах нет соответствующих форм. Это зафиксированная граница реализации, а не отсутствие API. Реальные финансовые операции и полное покрытие кабинета тестами не подтверждены.

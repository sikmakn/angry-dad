# Настройки

Можно изменить родителя, пол, часовой пояс, тихие часы и участие в рейтинге. Тихие часы длиннее 12 часов блокируют сохранение, равные начало/конец означают отсутствие интервала. Ошибка сохраняет редактируемые поля.

Профиль и участие сохраняются разными запросами: ошибка второго не откатывает уже успешный первый. После сохранения кеш боя очищается для чтения текущей роли. Старые сообщения не меняются; смена пояса меняет отображение времени, а не абсолютный момент срока.

Удаление требует двух подтверждений и чтения баланса перед окончательным действием. Экран предупреждает о потере данных и ударов. Только успешный ответ удаления очищает кеш и показывает завершение. При неизвестном результате нельзя утверждать, что аккаунт остался: UI предлагает завершить проверку удаления.

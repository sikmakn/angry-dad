# Одно уведомление

Страница `#notification/<id>` показывает карточку сообщения: тип, дату, название задачи, текст, прочтение и состояние проверки. Ссылка из Telegram `?notification=<id>` преобразуется в этот маршрут; старый `startapp=feed_<id>` тоже поддерживается. Сообщение ищется с последовательной догрузкой страниц ленты. Во время поиска виден индикатор; после исчерпания страниц - отдельное состояние «Уведомление не найдено».

Открытие вызывает `PUT /feed/{feedMessageId}/read`. Повтор сохраняет первую дату прочтения. При ошибке доступна отдельная кнопка повторной отметки. Это действие не отвечает на проверку.

Для проверки, которой нужен ответ, доступны «Сделано», «Делаю», «Не начинал» / «Не начинала». На время запроса кнопки отключены. Успех показывает сохранённый ответ и реплику; закрытие проверкой того же периода объясняется отдельно, без синтетического ответа. После пропуска 15 минут ответ ещё доступен до истечения дедлайна активной задачи. Кнопок продления и сдачи здесь нет: они находятся [в задаче](task.md).

Карточка показывает общий срок ответа группы, просрочку, фактическое списание только на верхней карточке группы и итог периода. Доступные реакции 😐 / 😞 / 😭 сохраняются сразу; выбранная оценка выделяется, её можно изменить. Ошибка ответа/оценки остаётся на странице.

«Ответить! 😠» добавляет цитату в перепалку и открывает диалог. До успешного запроса перехода нет; повтор после ошибки использует тот же ключ. Цитата не расходует удар и не отвечает на проверку. После ответа или закрытия проверки есть ссылка «К моим задачам»; возврат ведёт в историю.

# Рейтинг

Показывает серверный список лидеров по числу закрытых задач и собственную карточку/место. Участие можно выключить и вернуть на этом экране или в настройках. Публичный список содержит имя/username и число закрытий; задач и боёв других пользователей здесь нет.

Для пустого списка и собственного неучастия есть отдельные сообщения. Ошибку загрузки можно повторить. Сортировка, подсчёт закрытий и исключение неучастников — ответственность API, фронт отображает результат.

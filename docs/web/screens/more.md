# Ещё

Дополнительное меню ведёт в магазин ударов и настройки. Владелец видит вход в кабинет; окончательные права на его запросы проверяет сервер. Юридическая информация открывается в шторке с пояснением внешнего ИИ и ссылкой на опубликованные условия, если URL настроен.

Без окончательного legal URL показано объяснение о публикации владельцем. Это конфигурационное ограничение перед выпуском, а не готовый юридический текст.

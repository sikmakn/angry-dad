# Старт

Гость проходит выбор отца/матери, выбор пола, «Соболезнуем» и первые фразы, затем открывает первую задачу без нижнего меню. «Дальше» недоступно до выбора. На первом шаге доступны условия с пояснением передачи текстов внешнему ИИ; окончательный legal URL задаёт владелец.

При переходе после выбора пола отправляются роль, пол и пояс устройства; ошибка сохраняет выбор. Фразы берутся из ответа сервера. Пользователь с завершённым стартом получает основной интерфейс; разница поясов требует явного согласия на обновление.

Вне Telegram реальный режим показывает приглашение открыть бота, а при отсутствии username — сообщение о ненастроенной ссылке. MSW допускает демонстрационную сессию.

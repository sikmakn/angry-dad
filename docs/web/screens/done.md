# Готово

Закрытый период отображается внутри страницы задачи: название, размер, отметка выполнения, уважение и время закрытия. Сразу после действия показаны фраза и точная дельта из ответа сервера. Есть «Новая задача» и «Поделиться».

После reload остаются серверный статус и дельта периода, но похвала не восстанавливается из TaskResponse. UI не придумывает её. Это открытое [расхождение контракта](../../limitations/contract.md). У повторяющейся задачи доступны периоды и сведения о следующем старте.

# Перепалка

Экран текущего родителя показывает диалог, более ранние реплики, уважение, авторитет и количество оставшихся возможностей огрызнуться. Авторитет начинается со 100 и уменьшается после успешных ответов; ноль соответствует победе и смене поведения родителя. Каждый день терпения восстанавливает 25 авторитета до максимума 100. Внутренние поля API и базы `defeat` сохранены: UI и карточка «Поделиться» показывают `100 - defeat`, поэтому имеющийся прогресс сохраняется. Результат хода показывает снижение авторитета, например `100 → 79`.

Цвет авторитета соответствует целой части показателя: 100–61 красный, 60–21 жёлтый, 20–1 зелёный, 0 золотой. На нуле золотыми остаются число и контур шкалы, хотя заполнение равно нулю.

За впервые достигнутые пороги авторитета 80, 60, 40, 20 и 0 начисляется по +1 уважения. Победа дополнительно даёт +12, итого за первый полный проход +17 до действующих потолков уважения. Повтор запроса и повторное снятие восстановленного авторитета не оплачивают те же этапы заново.

При нулевом балансе можно открыть магазин шторкой, сохранив бой и черновик. «Поделиться» открывает подготовку карточки. Ошибки чтения имеют ручной повтор.

«Как это работает» показано над шкалами только до начала диалога (допускается одна стартовая фраза персонажа). После реплик, цитат или начала хода вводный блок скрывается. Нажатие карточки шкал открывает те же правила в попапе. У «Купить» отдельная кнопка поверх зоны правил в локальном stacking context карточки: она открывает магазин, не правила, и не перекрывает нижние элементы при прокрутке.

После неизвестного результата доступна проверка той же попытки с тем же key/body; после `turn_failed` текст сохраняется для новой попытки. Ключ не переживает размонтирование/reload, поэтому перед новой репликой нужно проверить диалог и баланс. Подробности: [данные боя](../data/battle.md).

Источники: [F-11](../../specs/mvp/functions/F-11-battle-dialog.md), [F-12](../../specs/mvp/functions/F-12-battle-turn.md), [макет](../../design/mvp/screens/battle.html), [BattleScreen](../../../apps/web/src/battle/BattleScreen.tsx), [useBattle](../../../apps/web/src/battle/hooks/useBattle.ts).

Ответ из уведомления добавляет цитату в текущий диалог перед переходом на экран. Удар расходуется только на отправку своей реплики, а проверка задачи остаётся без ответа до отдельного действия. Судья и актёр вызываются через [реальный ИИ или подставной режим](../../api/integrations/ai.md); при техническом отказе сервер возвращает удар и не фиксирует изменения шкал.

# Огрызнуться ещё

Показывает серверные пакеты, баланс и историю операций. Пользовательские подписи: «Можешь огрызнуться ещё N раз», «Огрызнуться 5 раз — 60 ⭐», кнопка отправки «Огрызнуться». При нулевом балансе — «Всё? А столько возражений было». В учётных операциях используются «попытки», API-поля `strikes` сохранены. Покупка запрашивает invoice и открывает окно Stars в Telegram. Из перепалки магазин открывается шторкой без потери черновика; в компактном варианте история операций скрыта.

Оплата доступна только вне моков в Telegram версии не ниже 6.1. После платёжного callback frontend ждёт обновления серверного баланса. До подтверждения зачисления второй платёж блокируется; долгое ожидание предлагает обновить баланс и обратиться к `/paysupport`. Ошибки чтения можно повторить; отмена/ошибка окна позволяет новую ручную попытку.

Реальная покупка и возврат Stars не выполнялись на текущем этапе. MSW показывает демонстрационные данные с отключённой покупкой.

# Постановка задачи

Форма принимает произвольное непустое название до 120 символов и выбор разового срока либо повторения. Сегодня/завтра выбирают день; поле «Время» доступно всегда, по умолчанию 22:00 в поясе профиля. Ручное время сохраняется при переключении дня, выбранный день остаётся подсвеченным. «Другая дата» дополнительно открывает календарь. Срок проверяется в пределах 15 минут — 365 дней. Поддерживаются ежедневное, будни, недельное, выбранные дни и каждые N дней с необязательным ориентиром. Для N вне 2…30 кнопка неактивна и показано объяснение.

Фразы периодичности в названии предлагают расписание, но сохраняет задачу только «Поставить». Ручной выбор имеет приоритет, предложение можно убрать. ИИ-проверки названия нет. Новые задачи получают средний размер; ответ персонажа выбирается из библиотеки универсальных фраз. После успеха видны сохранённая задача и серверная фраза; можно перейти к задачам или поставить следующую.

Явный отказ оставляет черновик. Во время отправки повтор заблокирован; неизвестный результат требует проверки списка и явного снятия guard. Подробности: [данные задач](../data/tasks.md), [восстановление](../../guide/recovery.md).

# Главная

Экран показывает уважение из профиля, текущую дату в его поясе, активные задачи, настроение/срок и переход к новой задаче. Ожидающая проверка ведёт к нужной задаче; у пропущенной проверки отображается предупреждение о снятом уважении.

Активные страницы дочитываются автоматически. Закрытые, проваленные и остановленные задачи доступны в раскрываемом архиве; для закрытых и остановленных предусмотрены отдельные кнопки следующих страниц. Карточка ведёт на hash-маршрут задачи, доступный после reload.

При пустом списке есть объяснение постановки задачи, при ошибке чтения — повтор. Расписание уведомлений и реальные проверки выполняет сервер, не главная страница.

# Главная

Экран показывает уважение из профиля, текущую дату в его поясе, активные задачи, настроение/срок и переход к новой задаче. Тексты уведомлений находятся в «Истории». Пока есть проверки активных задач без ответа, на главной показана только компактная надпись с их количеством, предупреждением о потере уважения за 15 минут молчания и ссылкой на историю. При нулевом `unansweredCount` надпись исчезает; чтение уведомления не считается ответом.

Надпись показывает секундный таймер ближайшего срока ответа по всем задачам (`nextAnswerDueAt`). В последнюю минуту красный контур медленно пульсирует с периодом 2,8 секунды; при `prefers-reduced-motion` остаётся статичным. Ссылка ведёт в историю, где первой стоит новая карточка самой срочной группы. После истечения срока таймер исчезает, предупреждение остаётся до ответа или закрытия задачи.

Активные страницы дочитываются автоматически. Закрытые, проваленные и остановленные задачи доступны в раскрываемом архиве; для закрытых и остановленных предусмотрены отдельные кнопки следующих страниц. Карточка ведёт на hash-маршрут задачи, доступный после reload.

При пустом списке есть объяснение постановки задачи, при ошибке чтения — повтор. Расписание уведомлений и реальные проверки выполняет сервер, не главная страница.

Источники: [F-4](../../specs/mvp/functions/F-4-one-time-task.md), [F-6](../../specs/mvp/functions/F-6-check-ins.md), [F-8](../../specs/mvp/functions/F-8-respect.md), [макет](../../design/mvp/screens/home.html), [HomeScreen](../../../apps/web/src/tasks/HomeScreen.tsx).

Таймер считает время **до ответа на уже доставленную проверку**, а не до отправки следующего уведомления. Число проверок считает сообщения, а не уникальные задачи.

# История

Лента показывает серверные сообщения с датами, контекстом задач и кнопкой следующих страниц. Текст сохранённого сообщения не пересобирается при смене родителя или пола; подпись автора в карточке берётся из текущей роли профиля (см. [ограничение](../../limitations/ai-and-notifications.md#подпись-автора-в-истории)).

У вкладки «История» показан счётчик активных уведомлений: непрочитанные сообщения и прочитанные проверки, которые ещё ждут ответа, без двойного счёта. Нулевой счётчик скрыт; значения выше 99 отображаются как `99+`. В карточках отдельно показаны «Не прочитано» / «Прочитано» и «Ждёт ответа» / «Ответ записан» / «Неактивно». Закрытые, удалённые, остановленные и просроченные периоды не требуют ответа.

Старые проверки закрытых периодов и проверки с уже записанным ответом не увеличивают счётчик даже без отметки о прочтении. Они сохраняются в истории с прежним состоянием прочтения.

У проверок одной задачи общий срок: 15 минут от первой доставленной проверки текущей группы без ответа. Чтение и новые уведомления срок не сдвигают. Ответ закрывает группу; последующая новая проверка начинает новый срок. Сначала идут ожидающие ответа группы с ближайшим сроком, внутри группы — самые новые карточки. Пагинация сохраняет этот порядок.

После истечения срока ответ ещё принимается, пока период активен и его дедлайн не истёк; уже начисленный штраф не возвращается. «Просрочено» показывается на всех карточках группы; фактическое списание всей группы добавляется только на верхней карточке (`groupRespectDelta`). Даже при открытии отдельной старой карточки списание не дублируется. Одна группа даёт не больше одного штрафа. «ОТВЕТ УЧТЁН» означает ответ на другую карточку, «ОТВЕЧЕНО» — ответ здесь. Для завершённого периода все карточки получают большую зелёную печать «ВЫПОЛНЕНО», для сдачи — красную «СДАЛСЯ» / «СДАЛАСЬ». Эти состояния заменяют печать просрочки.

На карточках ожидающих ответа проверок есть секундный таймер общего срока. В последнюю минуту контур медленно мигает красным; после ответа или истечения срока таймер исчезает.

Отдельная страница и её ошибки подробно описаны в [уведомлении](notification.md).

Прочитанным считается уведомление, открытое на отдельной странице приложения. Время сохраняется на сервере методом `PUT /feed/{feedMessageId}/read`; повторный вызов не меняет первую дату. Чтение не снимает обязанность ответить и не отменяет штраф за молчание. Счётчики обновляются каждые 3 секунды, открытая история и уведомление — каждые 5 секунд, поэтому состояние совпадает между экземплярами приложения после обновления данных.

Карточка записи отделяет автора, тип сообщения, время, задачу и текст. «Открыть сообщение» ведёт на отдельную страницу `#notification/<id>`. Её же открывает кнопка уведомления в Telegram; старые ссылки `startapp=feed_<id>` поддерживаются. Сообщение ищется по ID с догрузкой страниц ленты, без изменения API.

На странице проверки есть ответ «Сделано», «Делаю», «Не начинал(а)», результат ответа и оценка фразы. Действия самой задачи здесь не показываются. После ответа кнопки заменяются сохранённым ответом. Кнопка «Ответить! 😠» доступна и в истории, и на странице любого уведомления, включая проверки. Она сначала сохраняет фразу уведомления как реплику родителя в диалоге, затем открывает «Перепалка». При ошибке карточка остаётся открытой с возможностью повторить; повтор использует тот же ключ идемпотентности. Переход в бой сам по себе не отвечает на проверку.

Ответ закрывает остальные доставленные проверки того же периода задачи с пометкой «Закрыто без оценки», без изменения уважения и без выдуманного ответа. Их счётчики обновляются сразу после успешного запроса, без ожидания следующего опроса. Будущие проверки остаются самостоятельными. «Не начинал(а)» вызывает отдельную язвительную реплику; «Делаю» сохраняет прежние ответы.

Оценки 😐 / 😞 / 😭 означают «Слабо», «Неприятно», «В самое больное». Нажатие сразу сохраняет оценку и показывает реплику персонажа о частоте фразы. Выбранный смайлик выделяется заливкой и обводкой; другую оценку можно выбрать в любой момент. Повторное нажатие не добавляет новый голос. В Telegram выбранная кнопка получает синий стиль `primary`, остальные сохраняют стандартный фон; обновление оценки в приложении обновляет клавиатуру соответствующего уведомления. Ошибки чтения, рейтинга и ответа остаются видимыми; пустая лента и ненайденное уведомление имеют отдельные состояния.

# История

Лента показывает серверные сообщения с датами, контекстом задач и кнопкой следующих страниц. История не пересобирает старые фразы при смене родителя или пола.

У доступной для оценки фразы выбирают степень воздействия и подтверждают запись в шторке. Уже выставленная оценка показана без возможности изменить её. «Ответить» создаёт цитату по ID сообщения и переводит в бой только после успешного ответа. Ошибки рейтинга/цитаты остаются видимыми; чтение можно повторить. Пустая лента имеет отдельное сообщение.

# Telegram Bot API

API принимает webhook; worker отправляет плановые сообщения. Один Bot API клиент также используется для счетов и prepared inline messages. В режиме `EXTERNAL_CLIENTS_MODE=test` внешние вызовы подставные, независимо от того, существует ли реальный тестовый бот Telegram.

Для реальной работы нужны токен, согласованный webhook secret, доступный HTTPS endpoint `/api/telegram/webhook` и ссылки бота/Mini App. Регистрация webhook, права и доступность Telegram требуют отдельной операционной проверки. Подписанные данные Mini App проверяются сервером при каждом пользовательском запросе.

Отправка вне Mongo-транзакции: при потере ответа нельзя гарантировать единственную внешнюю доставку. Delivery учитывает ограничения скорости, 429/retry_after, блокировку/403 и осторожный интервал неизвестной отправки. Тихие часы и политика пользователя применяются к общему расписанию. Массовая доставка и NFR по задержкам не подтверждены нагрузочным прогоном.

Выполненные тесты использовали подставной клиент, прямые входящие updates и локальную генерацию PNG. Реальные Bot API, публикация карточки и клиенты Telegram не проверялись.

# Telegram Stars

Покупка использует XTR: ссылка на счёт → pre-checkout → подтверждение оплаты → однократное начисление. Одобрение pre-checkout и клиентское закрытие invoice не заменяют серверное подтверждение. Возврат владельцем относится к целому платежу.

Webhook, сверка истории Stars и восстановление `paid` сходятся в одном транзакционном пути. Неопределённость внешнего запроса нельзя исправлять ручным повторным начислением без сверки charge ID и финансовой истории. Ожидающий счёт без найденной операции остаётся ожидающим; несовпадения сохраняются как инциденты.

Подставной клиент в Jest не равен платёжной проверке в тестовой среде Telegram. До включения продаж N-15 требует тестовую среду без реальных Stars; такой живой прогон не выполнен. Возможность вывода/выплат и окончательная коммерческая конфигурация не подтверждены backend-тестами.

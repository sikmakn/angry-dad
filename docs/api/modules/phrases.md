# Phrases

Пул обслуживает реакции персонажа и плановые сообщения. Выбор учитывает категорию, роль, пол, уровень давления/побеждённости, качество и окно без повторов; шаблон подставляется под актуальный контекст. Фразы пула и ответы AI — разные источники текста.

Владелец читает и меняет пул, смотрит `GET /owner/phrase-coverage`, запрашивает перефразы. Генерация вариантов не означает их автоматического одобрения для показа. Оценка пользователем привязана к доступному сообщению feed и принимается по правилам контракта; голоса влияют на выбор/автовыключение.

Пагинация фраз может учитывать сортировку по показам или оценке. Передавайте курсор целиком: ID начальных фраз содержат подчёркивания. Перефразирование публикует событие журнала `paraphrase_generate` с количеством и ID сохранённых вариантов; журнал здесь best-effort и не откатывает успешную генерацию.

## Общие шаблоны и род

Начальный набор текстов общий для отца и матери; seed создаёт отдельные записи по ролям с одинаковым источником. Это не объединяет их оценки и не отменяет фильтры роли/комбинации. `[[parent:мужской вариант|женский вариант]]` зависит от роли родителя, `[[user:мужской вариант|женский вариант]]` - от пола пользователя. Совместимые формы `(а)` обрабатываются отдельно, для «говорил/сказал/предупреждал» учитывается родитель.

В новых исходных фразах используются короткие дефисы. Ответы реального ИИ нормализуются отдельно; рендер пула не заменяет тире произвольной фразы владельца. Seed обычно использует `$setOnInsert`: существующие тексты и правки владельца не переписываются массово, поэтому обновление исходников не мигрирует весь сохранённый пул.

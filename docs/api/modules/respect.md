# Respect

Единая точка изменения уважения применяет таблицу наград/штрафов и защищает запись от повторного начисления ключом события. Значение живёт в User, история причины — в RespectChange. Собственного REST API для произвольного изменения уважения нет, включая owner API.

Шкала ограничена диапазоном 0–100, шагом 0,5 и обычным потолком 94; рост выше обычного потолка связан со сломом в бою. Размер задачи влияет на награду, но не на вес одного выполнения в рейтинге. Дневные ограничения штрафов и награды за слом нельзя обходить сменой роли.

Переход задачи/боя вызывает модуль в своей транзакции: успешный HTTP-ответ не должен оставлять отдельно изменённую шкалу без соответствующего перехода. Формулы и причины не дублируются здесь: [F-8](../../specs/mvp/functions/F-8-respect.md), [RespectChange](../../architecture/mvp/entities/respect-change.md), [реализация](../../../apps/api/src/modules/respect/respect.service.ts).

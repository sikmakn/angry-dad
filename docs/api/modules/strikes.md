# Strikes

Баланс состоит из партий StrikeLot, а история — из StrikeOperation. Покупка и ручное начисление создают происхождение ударов; ход резервирует удар из доступной партии, успешное завершение расходует его, сбой возвращает. Денежная операция не переводится на best-effort события аналитики.

Пользователь читает `/me/strikes` и `/me/strike-operations`. Владелец может читать баланс/историю по Telegram ID и создавать ручную операцию с причиной; необязательный ключ повтора защищает её повтор в пределах контрактного срока. Владельцу не предоставляется изменение уважения.

Снимки платного происхождения и цены единицы сохраняются при резерве, чтобы поздняя смена пакета/курса не меняла экономику уже начатой попытки. Ручные/бесплатные партии не считаются платной выручкой. Возврат Stars разрешён только для целиком неиспользованной исходной партии у существующего пользователя; частичного возврата оставшихся ударов через эту операцию нет.

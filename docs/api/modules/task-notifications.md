# Единое расписание уведомлений

У пользователя одно сохранённое Mongo-расписание и не больше одного ожидающего сообщения планировщика. Независимого cron каждой задачи нет. `pressure` оставлен совместимым фасадом; политикой владеет `task-notifications`, HTTP-контроллеров у них нет.

Минимальный интервал — три минуты между успешными плановыми отправками; дополнительный предел — шесть автоматических сообщений за скользящий час. Это защитные границы, не обещание отправлять каждые три минуты. Срочность, застой, перенос и давность упоминания определяют основную задачу; иногда текст упоминает вторую. Кнопки и штраф относятся только к основной.

Следующее время выбирается один раз и сохраняется. Существенные изменения задач/профиля делают план неактуальным; обычное чтение не перерисовывает его на каждом тике. Перед подготовкой и отправкой проверяется актуальное состояние, тихие часы, onboarding, блокировка и удаление. После простоя пересчитываются текущие поводы вместо пачки старых сообщений.

Состояние защищено ревизией и арендой с токеном владельца. Неопределённый сетевой исход занимает осторожное окно частоты, не считается подтверждённой доставкой и не даёт гарантии единственной внешней отправки. Пятнадцать минут на ответ считаются от подтверждения отправки. Короткая серия ограничена двумя дополнительными обращениями; один исходный неответ не штрафуется многократно, дневной потолок штрафа за молчание сохраняется.

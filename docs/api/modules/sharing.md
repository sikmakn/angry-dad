# Sharing

`POST /shares` подготавливает карточку результата периода или боя. Проверяются владелец, состояние done/failed и текущая роль; удалённая задача и скрытый draft не являются допустимым источником результата. Карточка не содержит название личной задачи, имя или ответ AI: используется анонимизированный шаблон пула.

Сервер локально превращает SVG в PNG через sharp и передаёт изображение Telegram для prepared inline message. Ответ содержит `preparedMessageId`; это ещё не подтверждение отправки карточки в выбранный чат. При ошибке подготовки/Telegram возвращается `share_failed`.

В тестах проверялся настоящий локальный PNG и подставной Telegram; реальная публикация не выполнялась. Источники: [SharingService](../../../apps/api/src/modules/sharing/sharing.service.ts), [F-14](../../specs/mvp/functions/F-14-sharing.md), [результаты](../../testing/mvp-backend-results.md).

# Battle

Пользователь читает один диалог текущей роли и его сообщения через `/battle/{role}` и `/battle/{role}/messages`. Другая роль даёт `role_mismatch`. «Ответить» на feed добавляет цитату через `/battle/{role}/quotes` в существующий контекст, а не создаёт отдельный диалог. Цитата сама по себе не является платным ходом.

`POST /battle/{role}/messages` требует `Idempotency-Key`. Один незавершённый ход на диалог: резерв удара → судья → формулы → актёр → фиксация шкал/сообщений и расхода. Техническая ошибка, отказ или timeout возвращают удар и не фиксируют успешный результат шкал. Клиент должен учитывать серверный бюджет хода и описанный контрактом timeout запроса; повторять тот же ход нужно с прежним ключом, а новую попытку — с новым.

Побеждённость откатывается при чтении по времени, без отдельного cron. Слом и награда имеют ограничения на пользователя. Статусы задач бой не меняет. Формулы находятся в [F-12](../../specs/mvp/functions/F-12-battle-turn.md) и [damage](../../../apps/api/src/modules/battle/helpers/damage.ts).

Награда `battle_hit` определяется новыми порогами прогресса, а не оценкой base: `max(0, floor(defeatAfter / 20) - rewardedSteps)`. Поле `BattleDialog.rewardedSteps` хранит максимальный оплаченный этап (0–5) и не уменьшается при восстановлении авторитета. Переход через несколько этапов даёт соответствующее число баллов; старые диалоги без поля берут исходный этап из сохранённого прогресса без ретроначисления. Обновление этапа, уважения и результата хода — одна транзакция. На `defeatAfter = 100` дополнительно применяется прежний бонус +12 за победу с прежними ограничениями по частоте и потолкам уважения.

Worker восстанавливает зависшие ходы и сжимает контекст: при более чем 20 несжатых сообщениях сохраняет последние 8 и summary предыдущих. Обход BattleDialog идёт общими пачками 100 по `_id`, с продолжением и сбросом в конце, а не только для первых 100 пользователей. Курсор в памяти после рестарта начинает круг заново; CAS `summaryUpTo` защищает сохранение summary. Ход берёт готовое summary и все последующие сообщения, не ожидая фонового сжатия.

# Leaderboard

`GET /leaderboard` возвращает топ-100 и собственное место отдельно, включая место ниже сотого. Участвуют прошедшие onboarding пользователи с положительным числом закрытий, без удаления и с включённым участием. `PUT /me/leaderboard-participation` позволяет выйти и вернуться.

Порядок: число закрытий по убыванию, время достижения по возрастанию, затем ID для стабильного разрешения равенства. Размер задачи влияет на уважение, но каждое закрытие считается одной единицей рейтинга; удаление выполненной задачи корректирует счётчик. Рейтинг показывает поддержанные контрактом имя/username и счётчик, без задач или диалогов.

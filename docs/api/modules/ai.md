# AI

Шлюз выполняет пять задач: specificity, judge, actor, summary, paraphrase. Собственного HTTP API у него нет. Проверка задачи имеет суточную квоту по локальной дате пользователя; сбой не сохраняет задачу. Judge валидирует структурированный ответ и допускает до трёх попыток в общем бюджете хода; невалидный ответ не принимается за успешный.

На каждую попытку создаётся AiCall, включая отказы и невалидные ответы. Модель, тарифы и доступный usage сохраняются снимками. Таймаут без usage — неизвестная стоимость, подставной ответ — mock; ни то ни другое не доказывает нулевые расходы. Позднее usage после локального таймаута автоматически не сверяется.

Все пять целей по умолчанию используют `openai/gpt-oss-120b`; доступны общее и отдельные переопределения модели. Смена модели требует согласования тарифов каждой цели. В запросы передаётся контекст задачи/перепалки без Telegram ID, имени и username; внутренний userId для учёта не означает передачу идентичности провайдеру.

Реальный OpenAI-совместимый провайдер подключён; `EXTERNAL_CLIENTS_MODE=test` возвращает подставные ответы без сети.

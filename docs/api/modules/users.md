# Users

Модуль отвечает за вход Telegram, профиль, onboarding, настройки и удаление аккаунта. Основной поток: `GET /me` → при необходимости `POST /me/onboarding` → пользовательские операции. `PATCH /me` меняет поддержанные контрактом настройки; IANA-зона нужна календарным правилам и тихим часам.

Смена роли не создаёт обход ограничений награды за слом: часть состояния относится ко всему пользователю. Обычные запросы работают только со своими ресурсами; owner-поиск по Telegram ID не открывает чужую историю задач/боя.

Открытие через `GET /me` и пользовательские мутации наблюдают активность после проверки входа. Обычные GET-чтения, owner-действия и удаление аккаунта не служат посещением. `lastActivityAt` сохраняется синхронно, статистика публикуется отдельно и может запаздывать. Не используйте `GET /me` как фоновый polling активности.

Удаление отключает пользователя от рейтинга и помечает удаляемым, затем транзакционно очищает нефинансовые данные. Финансовая история и обезличенные записи имеют отдельные правила: [данные User](../data/user.md).

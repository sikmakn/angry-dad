# User и удаление

User связывает Telegram-вход, настройки, операционную активность, уважение и рейтинг. Поля публичного профиля определяются DTO/OpenAPI; внутренние поля не нужно отправлять клиенту только потому, что они есть в Mongo-схеме.

`lastActivityAt` нужен расписанию и не зависит от успешности асинхронной статистики. `lastSentAt` участвует в общем интервале доставок. UserStatistics хранит первые события, UserActivityDay — дни UTC; эти отдельные модели не заменяют операционное состояние User.

При удалении стираются задачи/периоды, диалоги/ходы, feed/outbox, состояние уведомлений, статистика, персональные оценки и дневные счётчики. Партии ударов обнуляются, финансовые записи сохраняются; у AiCall и AnalyticsEvent снимается связь `userId`. DeletedUser хранит хеш Telegram ID для правил повторной регистрации. Нельзя обещать удаление всей финансовой истории или восстановление прежних задач после повторного входа.

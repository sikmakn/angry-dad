# RoleCard · [← сводка](../00-overview.md)

Карточка роли для судьи и актёра: характер и больные места.

**Связи:** —
**Сценарии:** UC-70, UC-71 ([привязка](../use-cases.md))
**Модуль-владелец:** [battle](../modules.md#battle)

## Поля
| поле | тип | обязательное | откуда значение | кто пишет | в API |
|---|---|---|---|---|---|
| `role` | enum(father, mother) | да | ввод владельца | battle | админу |
| `character` | string | да | ввод владельца | battle | админу |
| `weakSpots` | list({key, description}) | да | ввод владельца | battle | админу |
| `version` | int | да | вычисляется | battle | нигде |

«В API»: владельцу — хозяину записи; админу — владельцу продукта.

## Инварианты
- больных мест не меньше 5

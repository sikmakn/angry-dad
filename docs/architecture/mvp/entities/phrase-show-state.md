# PhraseShowState · [← сводка](../00-overview.md)

Недавние показы фраз пользователю для окна без повторов (R-83).

**Связи:** → User
**Сценарии:** UC-57 ([привязка](../use-cases.md))
**Модуль-владелец:** [phrases](../modules.md#phrases)

## Поля
| поле | тип | обязательное | откуда значение | кто пишет | в API |
|---|---|---|---|---|---|
| `userId` | ref(User) | да | вычисляется | phrases | нигде |
| `recent` | list(ref(Phrase)) по ключу категории | да | вычисляется | phrases | нигде |

«В API»: владельцу — хозяину записи; админу — владельцу продукта.

## Инварианты
- хранится не больше нужного окна (до 5 на ключ)

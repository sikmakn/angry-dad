# PhraseVote · [← сводка](../00-overview.md)

Голос пользователя за фразу; один на пару.

**Связи:** → Phrase, User
**Сценарии:** UC-54…UC-58 ([привязка](../use-cases.md))
**Модуль-владелец:** [phrases](../modules.md#phrases)

## Поля
| поле | тип | обязательное | откуда значение | кто пишет | в API |
|---|---|---|---|---|---|
| `userId`, `phraseId` | ref | да | вычисляется | phrases | нигде |
| `score` | enum(0, 1, 2) | да | ввод пользователя | phrases | владельцу |
| `at` | date | да | генерируется | phrases | нигде |

«В API»: владельцу — хозяину записи; админу — владельцу продукта.

## Инварианты
- пара (userId, phraseId) уникальна; при удалении аккаунта голос стирается, счётчики Phrase остаются

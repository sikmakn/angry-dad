# DailyCounter · [← сводка](../00-overview.md)

Счётчик суточного лимита по местной дате пользователя.

**Связи:** → User
**Сценарии:** UC-16 ([привязка](../use-cases.md))
**Модуль-владелец:** [ai](../modules.md#ai)

## Поля
| поле | тип | обязательное | откуда значение | кто пишет | в API |
|---|---|---|---|---|---|
| `userId` | ref(User) | да | вычисляется | ai | нигде |
| `kind` | enum(specificity) | да | вычисляется | ai | нигде |
| `localDate` | дата местная | да | вычисляется | ai | нигде |
| `count` | int | да | вычисляется | ai | нигде |

«В API»: владельцу — хозяину записи; админу — владельцу продукта.

## Инварианты
- (userId, kind, localDate) уникальна; удаляется через несколько суток

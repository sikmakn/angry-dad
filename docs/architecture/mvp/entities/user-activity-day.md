# UserActivityDay

Один факт активности пользователя за календарный день UTC. Модуль analytics, в API напрямую не отдаётся. Источники и формулы — [аналитика](../analytics.md).

- `userId` — ссылка на User.
- `day` — дата начала суток UTC.
- `firstActivityAt`, `lastActivityAt` — первая и последняя наблюдавшиеся активности дня; обновляются через `$min`/`$max`.

Запись обновляет асинхронный подписчик `user.activity.observed`/`task.created` по исходному времени события. По [D8](../analytics.md#доставка-событий-по-d8) редкая потеря события допустима. Операционный `User.lastActivityAt` обновляется отдельно в users синхронно и не зависит от этой проекции. Позднее событие после удаления аккаунта игнорируется.

Уникальный индекс `{userId, day}` исключает размножение факта при повторах; индекс `{day, lastActivityAt, firstActivityAt}` поддерживает выбор периода. Это дневной учёт, а не журнал каждого запроса или числа запусков. Внутренние посещения между двумя отметками не восстанавливаются; активные считаются по целым выбранным UTC-дням. TTL нет. Запись защищена от воскрешения при удалении User, очищается в транзакции удаления аккаунта. Текстов и Telegram-идентификаторов нет.

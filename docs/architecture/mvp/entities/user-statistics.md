# UserStatistics

Модель модуля analytics для первых событий пользователя по [D7](../analytics.md). В API напрямую не отдаётся.

- `userId` — ссылка на User, уникальный индекс: одна запись на аккаунт.
- `firstStartedAt?` — первый личный `/start` или открытие Mini App; повторное событие не переносит начало вперёд.
- `firstTaskCreatedAt?` — минимальное исходное время создания из полученных `task.created`. Событие публикуется после коммита Task; статистику обновляет подписчик в отдельной транзакции через `$min`.

Индекс `{firstStartedAt, userId}` поддерживает выбор стартовой когорты. Отсутствующие времена не заменяются предположениями о прошлой активности. По [D8](../analytics.md#доставка-событий-по-d8) обновление асинхронное, редкая потеря события допустима; порядок обработки не заменяет исходное время события. Запись защищена проверкой и изменением существующего, не удаляемого User в транзакции подписчика, удаляется вместе с аккаунтом. Позднее событие удалённого пользователя игнорируется. Текстов и Telegram-идентификаторов нет.

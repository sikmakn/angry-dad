# FeedMessage · [← сводка](../00-overview.md)

Отправленное или показанное сообщение персонажа: «История», проверка с ответом, оценка.

**Связи:** → User, Phrase, Period
**Сценарии:** UC-32…UC-36, UC-54…UC-60 ([привязка](../use-cases.md))
**Модуль-владелец:** [delivery](../modules.md#delivery)

## Поля
| поле | тип | обязательное | откуда значение | кто пишет | в API |
|---|---|---|---|---|---|
| `id` | id | да | генерируется | система | владельцу |
| `userId` | ref(User) | да | вычисляется | delivery | нигде |
| `phraseId` | ref(Phrase) | нет | вычисляется | delivery | нигде |
| `category` | enum(категории пула) | да | вычисляется | delivery | владельцу |
| `text` | string | да | копия-снимок подстановки (R-13: старые не меняются) | delivery | владельцу |
| `periodId`, `taskTitle` | ref(Period), string | нет | копия-снимок названия для «Ответить» (R-87) | delivery | владельцу |
| `telegramMessageId` | int | нет | внешний сервис | delivery | нигде |
| `checkIn` | {answer, answeredAt, missedAt} | для проверок | ввод пользователя / вычисляется | pressure | владельцу |
| `rating` | enum(0, 1, 2) | нет | ввод пользователя | phrases | владельцу |
| `sentAt` | date | да | генерируется | delivery | владельцу |

«В API»: владельцу — хозяину записи; админу — владельцу продукта.

## Инварианты
- оценку можно поставить один раз на фразу (через PhraseVote)

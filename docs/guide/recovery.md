# Восстановление после ошибки

Ошибка чтения позволяет нажать «Повторить». При устаревшем входе открой Mini App заново через Telegram. Текст серверного отказа объясняет недопустимое действие; черновики создания и редакторов сохраняются в пределах описанных экранов.

## Неизвестный результат создания задачи

Потеря связи не доказывает, что задача не создана. Форма блокирует новый POST и при доступном sessionStorage сохраняет блокировку после reload. Нажми «Обновить список задач», проверь все загруженные записи. Если задача есть — открой её. Для возврата к форме поставь явное подтверждение проверки и нажми «Вернуться к форме без отправки». Эта кнопка сама ничего не отправляет; новый «Поставить» — отдельное осознанное действие с риском дубля, если первый запрос ещё завершается.

При недоступном storage защита в памяти сохраняется при навигации, но не гарантируется после reload. См. [данные задач](../web/data/tasks.md).

## Неизвестный результат боя

Оставаясь на экране, проверяй ту же попытку: key/body не меняются. После ухода/reload ключ попытки теряется; проверь сообщения, обработку и баланс до новой реплики. Определённый `turn_failed` отличается от потери ответа: сервер сообщает незасчитанный ход, UI сохраняет текст для новой попытки. См. [данные боя](../web/data/battle.md).

## Другие записи

Для завершения периода, продления, редактирования, удаления и операций владельца нет общей гарантии повторной отправки по ключу. Обнови данные перед новой записью. При неизвестном результате удаления аккаунта UI не заявляет, что аккаунт сохранился. При ожидании оплаты дождись баланса вместо нового платежа. Настройки профиля и участия сохраняются отдельно: ошибка участия не откатывает успешную запись профиля.

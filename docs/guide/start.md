# Первый запуск

1. Открой Mini App из бота Telegram. Обычный браузер без Telegram-входа показывает приглашение вернуться в платформу; ссылка на бота появится после настройки username владельцем.
2. Выбери родителя, открой условия и пояснение внешнего ИИ, затем нажми «Дальше».
3. Выбери пол и продолжи. При ошибке сохранения выбор остаётся: повтори явно после восстановления связи.
4. Пройди «Соболезнуем» и первые реплики, открой форму первой задачи. Её поля не отправляются без «Поставить».

После завершённого старта доступно нижнее меню. Если пояс устройства отличается от сохранённого, приложение предложит обновление; отказ оставляет прежний пояс. Настройки позволяют сменить родителя/пол и участие в рейтинге. История старых фраз остаётся прежней.

В демонстрационном MSW режиме используются образцы сессии и данных; это отдельно от настоящего входа. См. [старт](../web/screens/start.md), [настройки](../web/screens/settings.md), [конфигурацию](../web/setup.md).

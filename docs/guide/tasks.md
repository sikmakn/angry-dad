# Работа с задачей

1. На главной выбери «Новая задача», напиши конкретное действие.
2. Выбери срок разовой задачи или расписание повторяющейся. Предложение по словам в названии можно изменить или убрать. Проверь пояс, дату, время и необязательный ориентир.
3. Нажми «Поставить» и дождись серверного результата. При отказе исправь поля; при неизвестном исходе используй [восстановление](recovery.md).
4. Открой карточку. «Готово» закрывает активный период; ответы на проверку позволяют сообщить «Сделано», «Частично» или «Не начинал» / «Не начинала». Уважение и итоговую фразу возвращает сервер.
5. При необходимости запроси ещё час либо подтверди «Сдаюсь». Допустимость продления проверит сервер, заранее использованное продление UI пока не распознаёт.

У проваленного периода доступен «Сделаю за час», пока повтор допустим; снятое уважение не возвращается. «Ответить» переносит цитату в бой. Повторяющуюся задачу можно остановить, сохранив просмотр периодов. Удаление требует подтверждения и убирает задачу из списка/истории согласно серверным правилам.

Архив раскрывается на главной: «Завершённые, проваленные и остановленные». Карточка доступна после reload по адресу; похвала успеха после reload пока не восстанавливается. См. [задачу](../web/screens/task.md), [Готово](../web/screens/done.md), [Провал](../web/screens/fail.md).

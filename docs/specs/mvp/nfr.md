# Нефункциональные требования · [← ТЗ](spec.md)

| id | область | требование |
|---|---|---|
| N-1 | языки | Интерфейс бота и Mini App, фразы и бой только на русском языке. Обращение к пользователю на «ты» в фразах персонажа, на «Вы» в системных экранах старта (как в `source.md`) |
| N-2 | производительность | Ход боя от отправки реплики до показа ответа: не больше 10 с для 95% ходов; при превышении 30 с ход завершается ошибкой по R-94 (A-39, A-55) |
| N-3 | производительность | Сообщение по расписанию отправляется не позже чем через 1 минуту после запланированного времени для 99% сообщений (A-55) |
| N-4 | доступность | После простоя сообщения, опоздавшие больше чем на 15 минут, не отправляются, кроме первого onFail по каждой проваленной задаче; переходы статусов по дедлайнам применяются с опозданием, но по времени дедлайна (A-55) |
| N-5 | производительность | Экран Mini App открывается не дольше 2 с для 95% открытий при работающей сети (A-55) |
| N-6 | лимиты | Система рассчитана на 10 000 активных пользователей в сутки и 100 одновременных ходов боя (A-55, Q-8) |
| N-7 | лимиты | Система соблюдает лимиты Telegram Bot API на рассылку; при упоре в лимит сообщение откладывается, а не теряется (кроме правила N-4) |
| N-8 | доступность | Сервис доступен не меньше 99% времени за календарный месяц (A-55) |
| N-9 | доступность | Mini App работает в официальных клиентах Telegram для iOS, Android, Desktop и Web, поддерживающих Mini App и Stars; кнопки не меньше 44×44 pt, контраст текста не меньше 4.5:1, все сообщения понятны без звука (A-55) |
| N-10 | безопасность | Система принимает действия из Mini App только от пользователя, подлинность которого подтверждена данными запуска Telegram; пользователь не может прочитать или изменить чужие задачи, диалоги, баланс |
| N-11 | приватность | Во внешний ИИ передаются только название задачи, реплики диалога, карточка роли, полы и состояние персонажа; Telegram ID, username и имя не передаются (A-56) |
| N-12 | безопасность | Собственного списка запрещённых тем нет; содержание фраз пула контролирует владелец при добавлении (R-127, R-128), ответы актёра ограничены только политикой провайдера ИИ (D8) |
| N-13 | приватность | Удаление аккаунта (R-17) выполняется сразу после подтверждения: удалённые данные больше не показываются нигде, включая владельца (A-6) |
| N-14 | лимиты | Средняя стоимость токенов хода не больше 30% выручки с удара после комиссии Telegram (из целевой маржи 70% в `source.md`); бюджет ИИ в бесплатном ядре на пользователя в сутки — Q-2 |
| N-15 | безопасность | Платежи проверяются в тестовой среде Telegram без реальных Stars до включения продаж |
| N-16 | лимиты | Вызовы ИИ в бесплатном ядре (проверка конкретности) ограничены суточным лимитом на пользователя (R-28, D9) и при сбое не сохраняют задачу (R-26, D11) |
| N-17 | приватность | Система собирает события аналитики для метрик: старт пройден, задача создана, проверка отправлена и отвечена, задача или период done и failed, оценка фразы, ход боя (стоимость в токенах), покупка, возврат, «Поделиться», блокировка бота, удаление аккаунта; события не содержат текстов задач и реплик |
| N-18 | качество | Автоматические тесты покрывают формулы боя (R-97, R-98, R-102, R-104, R-105), выбор фраз (R-81…R-83), сценарии хода боя (R-94…R-96) и расписание уведомлений (R-48…R-50, R-57…R-62) |

## Метрики

Собираются с первого дня, пороги, кроме указанных в [ТЗ](spec.md#цель-и-успех), не заданы (Q-8). Владелец видит их по R-132.

Уточнение Никиты от 2026-10-24 ([D7](../../architecture/mvp/decisions.md#принято)): формулы D7, активности и первой задачи, USD и настраиваемые тарифы закреплены в [аналитике](../../architecture/mvp/analytics.md). Первый прямой запуск Mini App без `/start` тоже начинает замер; повторный запуск его не сбрасывает. Для N-14 используется согласованная оценка `$0.013/Star`, без отдельного расчёта налогов/вывода. Настоящий ИИ пока не подключается.

| метрика | что показывает |
|---|---|
| Возврат на 7-й день | живёт ли продукт после первой шутки |
| Доля закрытых задач и периодов | работает ли давление |
| Доля отвеченных проверок | эффективность проверок |
| Конверсия в первую покупку | работает ли триггер «Ответить» |
| Средняя стоимость хода в токенах / выручка с удара | экономика боя |
| Доля пользователей, заблокировавших бота | не перегибает ли давление (вместо «мутов»: мут боту не виден) |
| Средний балл фраз | качество контента |
| Пересылок карточки на 100 активных пользователей | работает ли шеринг |
| Медиана времени от `/start` до первой сохранённой задачи | понятен ли старт (без порога, A-59) |

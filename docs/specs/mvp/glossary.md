# Глоссарий · [← ТЗ](spec.md)

| термин | значение |
|---|---|
| персонаж, родитель, роль | Отец или мать, выбранные пользователем; говорит во всех фразах и в бою |
| пол пользователя | Мужской или женский, выбирается на старте; определяет окончания обращения |
| задача разовая | Задача с одним дедлайном |
| задача повторяющаяся | Задача с периодичностью; состоит из периодов |
| период | Один интервал повторяющейся задачи (день, будний день, выбранный день недели, неделя или N дней) со своим сроком и статусом; начинается в 00:00 своего первого дня (A-67) |
| активная повторяющаяся задача | Повторяющаяся задача в статусе active, у которой сейчас есть активный период; без активного периода (выходные у задачи «по будням», время после «Готово» за сегодня) проверки, напоминания и onAbsent по ней не идут (A-67) |
| дедлайн, срок периода | Момент времени, после которого задача или период без «Готово» считается проваленным; у периода это 22:00 последнего дня периода или заданное время, если оно позже 22:00 (D22) |
| ориентир | Время, заданное у повторяющейся задачи («примерно в 20:00»); от него считаются напоминания и настроение, но провала в этот момент нет (D22) |
| закрытая задача | Разовая задача или период в статусе done |
| размер задачи | Микро, средняя или большая; определяется лёгкой моделью при постановке (R-134) и задаёт награду за закрытие: +1, +3 или +5 уважения (D24) |
| настроение | Уровень раздражения персонажа по задаче: neutral, watching, annoyed, angry, very_angry (R-39) |
| проверка | Сообщение «покажи, что сделано» с тремя кнопками ответа в случайный момент |
| случайное расписание | Проверки задачи в случайные моменты по R-48 и R-49, без учёта серий (A-64) |
| серия | Две дополнительные проверки с интервалом 3–10 минут после застоя (R-50); у задачи одновременно не больше одной серии, проверки серии новых серий не запускают (A-63) |
| тихие часы | Интервал местного времени без сообщений по расписанию; по умолчанию 23:00–08:00; длина 0 — тихих часов нет |
| конец тихих часов, «утро» | Момент окончания тихих часов; «утро» после провала — первый конец тихих часов после провала; при тихих часах длиной 0 — 08:00 (A-72) |
| сутки, «сегодня» | Календарные сутки в часовом поясе пользователя с 00:00 до 24:00 (A-7) |
| активность | Открытие Mini App, любое сообщение или нажатие кнопки в боте (A-26) |
| уважение | Шкала 0–100, отражает, насколько персонаж уважает пользователя; одна на пользователя; выше 94 поднимается только сломом персонажа (D17) |
| фраза | Одна запись пула с вариантами по роду; единица оценки и статистики |
| ячейка пула | Набор фраз с одинаковыми ролью, категорией, уровнем, уровнем побеждённости и сочетанием (полный ключ, A-66) |
| кандидаты | Фразы, из которых выбирается фраза для сообщения: ячейки той же роли, категории и уровня с текущими или «любыми» уровнем побеждённости и сочетанием; конкретные фразы при равных оценках выбираются чаще (R-73, R-75, A-66) |
| удар | Внутренняя единица оплаты: одна реплика игрока в бою; покупается за Stars |
| ход | Одна реплика игрока и ответ персонажа со всеми пересчётами |
| диалог боя | Вся переписка пользователя с одной ролью в бою; один на пару «пользователь, роль» |
| побеждённость, степень победы (defeat) | Шкала 0–100: насколько пользователь прижал персонажа в бою; хранится на пару «пользователь, роль»; вторая и последняя шкала, кроме уважения (D15) |
| слом | Момент, когда побеждённость дошла до 100 |
| откат | Постепенное снижение побеждённости до 0 за 4 суток |
| актёр | ИИ, который пишет ответы персонажа в бою |
| судья | ИИ, который оценивает реплику игрока структурой без текста |
| карточка роли | Описание роли для ИИ: характер и список больных мест |
| карточка для шеринга | Изображение с фразой персонажа из пула и ссылкой на бота, без имени и названия задачи |
| карточка рейтинга | Строка рейтинга: username (или имя) и число закрытых задач; есть у каждого, кто не вышел из рейтинга (D21) |
| владелец | Хозяин продукта, модерирует пул, разбирает платежи; определяется по Telegram ID |

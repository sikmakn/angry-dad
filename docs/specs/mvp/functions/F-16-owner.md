# F-16 Функции владельца

**Кто:** владелец · **Суть:** владелец наполняет и чистит пул фраз, настраивает карточки ролей и цены, разбирает платежи и смотрит метрики · [← ТЗ](../spec.md)

Канал выполнения функций владельца (команды бота, отдельная страница) выбирает архитектор.

## Требования
| id | требование | критерий приёмки | сценарии |
|---|---|---|---|
| R-126 | Система даёт функции владельца только пользователю с Telegram ID владельца из настройки системы (A-54) | Когда обычный пользователь пытается открыть функцию владельца, тогда получает отказ и ничего не меняется | [UC-24](F-4-one-time-task.md#uc-24), [UC-76](F-13-payments.md#uc-76), [UC-93](#uc-93) |
| R-127 | Система даёт владельцу добавить фразу с полями R-70 и автором (фразы подписчиков из постов-сборов вносит владелец вручную); автор виден только владельцу (A-53) | Когда владелец добавляет фразу с автором «@ivan», тогда она есть в пуле, а пользователи автора не видят | [UC-89](#uc-89) |
| R-128 | Система по запросу владельца создаёт перефразы выбранной фразы моделью в той же структуре (подстановка переменных и синонимы, без новых тем); перефраз попадает в пул только после одобрения владельцем как отдельная фраза (A-53) | Когда владелец отклоняет перефраз, тогда он не показывается пользователям | [UC-89](#uc-89) |
| R-129 | Система показывает владельцу список выключенных фраз и фраз «ниже порога» с avg и votes и даёт вручную включить или выключить любую фразу, кроме последней включённой фразы ячейки с уровнем побеждённости «любой» и сочетанием «любое» (A-66) | Когда владелец включает автовыключенную фразу, тогда она снова участвует в выборе; когда пытается выключить последнюю фразу ячейки «любой» × «любое», тогда видит отказ «В ячейке не останется фраз» | [UC-90](#uc-90), [UC-92](#uc-92), [UC-94](#uc-94) |
| R-130 | Система даёт владельцу менять карточку роли (описание характера, больные места) и пакеты ударов (R-111); изменение карточки действует на новые ходы | Когда владелец добавляет больное место, тогда судья в следующем ходе может его вернуть | [UC-70](F-12-battle-turn.md#uc-70), [UC-90](#uc-90) |
| R-131 | Система показывает владельцу баланс и историю операций пользователя по Telegram ID и даёт начислить или вернуть удары с обязательной причиной; операция появляется в истории пользователя | Когда владелец начисляет 2 удара с причиной «возврат по жалобе», тогда баланс пользователя вырос на 2, и в его истории есть запись с этой причиной | [UC-76](F-13-payments.md#uc-76), [UC-91](#uc-91) |
| R-132 | Система показывает владельцу метрики из раздела [«Метрики»](../nfr.md#метрики) за выбранный период | Когда владелец выбирает последние 7 дней, тогда видит значения всех метрик за эти дни | [UC-90](#uc-90) |
| R-133 | Система записывает каждое действие владельца (что, когда, над чем) в журнал, который владелец может просмотреть (A-54) | Когда владелец начислил удары, тогда в журнале есть запись с датой, пользователем и числом ударов | [UC-93](#uc-93) |

## Сценарии
Типы: основной, альтернативный, ошибка, граница, права, пустое состояние. Тип, который не применим, записан явно с причиной.

### UC-89
**Тип:** основной · **Роль:** владелец · **Требования:** R-127, R-128
**Шаги:**
1. Добавляет фразу подписчика с автором «@ivan» в onFail отца, уровень побеждённости «любой».
2. Запрашивает перефразы этой фразы, одобряет один, отклоняет другой.
**Результат:** фраза и одобренный перефраз в пуле как отдельные фразы; отклонённый не показывается; пользователи автора не видят.

### UC-90
**Тип:** альтернативный · **Роль:** владелец · **Требования:** R-129, R-130, R-132
**Шаги:**
1. Открывает список выключенных фраз, включает одну.
2. Меняет цену пакета «Три» на 42 Stars.
3. Смотрит метрики за 7 дней.
**Результат:** фраза снова участвует в выборе; пользователи видят цену 42; метрики за период показаны.

### UC-91
**Тип:** ошибка · **Роль:** владелец · **Требования:** R-131
**Что идёт не так:** владелец пытается начислить удары без причины.
**Поведение:** операция отклонена с сообщением «Укажите причину», баланс не изменился.

### UC-92
**Тип:** граница · **Роль:** владелец · **Требования:** R-129, R-82
**Шаги:**
1. Пытается выключить последнюю включённую фразу ячейки уровня побеждённости «любой» и сочетания «любое».
**Результат:** отказ «В ячейке не останется фраз», фраза включена.

### UC-93
**Тип:** права · **Роль:** пользователь, владелец · **Требования:** R-126, R-133
**Шаги:**
1. Обычный пользователь пытается открыть функцию владельца.
2. Владелец начисляет удары.
**Результат:** пользователю отказ, ничего не меняется; действие владельца записано в журнал с датой, пользователем и числом ударов.

### UC-94
**Тип:** пустое состояние · **Роль:** владелец · **Требования:** R-129, R-116
**Предусловия:** выключенных фраз и обращений `/paysupport` нет.
**Результат:** списки показывают «Выключенных фраз нет» и «Обращений нет».

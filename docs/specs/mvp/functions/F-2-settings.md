# F-2 Профиль, настройки и удаление аккаунта

**Кто:** пользователь · **Суть:** пользователь меняет родителя, пол, часовой пояс, тихие часы и участие в рейтинге или удаляет аккаунт · [← ТЗ](../spec.md)

## Требования
| id | требование | критерий приёмки | сценарии |
|---|---|---|---|
| R-11 | Система показывает страницу «Настройки» с полями: родитель, пол пользователя, часовой пояс, тихие часы, участие в рейтинге, кнопка «Удалить аккаунт» | Когда пользователь открывает «Настройки», тогда видит все шесть элементов с текущими значениями | [UC-7](#uc-7), [UC-84](F-15-leaderboard.md#uc-84) |
| R-12 | Система при смене родителя говорит от нового родителя во всех следующих фразах; задачи и уважение сохраняются; побеждённость и диалог боя у каждой роли свои (D5, A-61) | Когда пользователь меняет отца на мать, тогда следующая проверка приходит от матери, уважение не меняется, а страница «Бой» показывает диалог с матерью (пустой, если боя с ней не было) | [UC-7](#uc-7), [UC-64](F-11-battle-dialog.md#uc-64) |
| R-13 | Система при смене пола пользователя применяет новые окончания во всех следующих фразах; уже отправленные сообщения не меняются | Когда пользователь меняет пол с мужского на женский, тогда следующая фраза содержит «не сделала», а в «Истории» старые сообщения остались с «не сделал» | [UC-8](#uc-8) |
| R-14 | Система при смене часового пояса не сдвигает моменты дедлайнов, а показывает их в новом поясе; тихие часы и суточные правила считаются по новому поясу (A-4) | Когда дедлайн 18:00 по UTC+3 и пользователь выбирает UTC+4, тогда задача показывает дедлайн 19:00 | [UC-8](#uc-8) |
| R-15 | Система позволяет задать начало и конец тихих часов с шагом 30 минут, длительностью от 0 до 12 часов; по умолчанию 23:00–08:00; длительность 0 означает, что тихих часов нет, а концом тихих часов («утро» в R-46, R-59) тогда считается 08:00 (решение C-7, A-5, A-72) | Когда пользователь задаёт 22:00–10:00, тогда настройка сохраняется; когда задаёт 20:00–10:00, тогда видит ошибку «Тихие часы не длиннее 12 часов» | [UC-9](#uc-9) |
| R-16 | Система удаляет аккаунт только после двух подтверждений; во втором предупреждает, что неизрасходованные удары сгорят, и показывает их число (A-6) | Когда у пользователя 4 удара и он нажимает «Удалить аккаунт», тогда видит текст «4 удара сгорят» и кнопку окончательного удаления | [UC-10](#uc-10), [UC-12](#uc-12) |
| R-17 | Система после удаления стирает профиль, задачи, периоды, ленту сообщений, диалоги боя, уважение, побеждённость, карточку в рейтинге; сохраняет записи платежей, обезличенные счётчики оценок фраз и признак «уже был» (A-6), и прекращает все сообщения | Когда аккаунт удалён, тогда бот не присылает ни одного сообщения по расписанию, пользователь пропадает из рейтинга, а владелец видит его платежи без задач и диалогов | [UC-10](#uc-10), [UC-11](#uc-11) |

## Сценарии
Типы: основной, альтернативный, ошибка, граница, права, пустое состояние. Тип, который не применим, записан явно с причиной.

### UC-7
**Тип:** основной · **Роль:** пользователь · **Требования:** R-11, R-12
**Предусловия:** выбран отец, есть активные задачи, бой с отцом начат (побеждённость 30).
**Шаги:**
1. Открывает «Настройки», меняет родителя на «мать».
2. Ждёт следующую проверку, открывает «Бой».
**Результат:** проверка приходит от матери; уважение и задачи прежние; «Бой» показывает диалог с матерью (пустой, побеждённость 0); при возврате к отцу диалог и побеждённость отца прежние (с учётом отката).

### UC-8
**Тип:** альтернативный · **Роль:** пользователь · **Требования:** R-13, R-14
**Шаги:**
1. Меняет пол на «женский».
2. Меняет часовой пояс с UTC+3 на UTC+4.
**Результат:** новые фразы с женскими окончаниями, старые в «Истории» без изменений; дедлайн 18:00 показан как 19:00, момент дедлайна не изменился; тихие часы считаются по UTC+4.

### UC-9
**Тип:** ошибка · **Роль:** пользователь · **Требования:** R-15
**Что идёт не так:** пользователь задаёт тихие часы 20:00–10:00 (14 часов).
**Поведение:** ошибка «Тихие часы не длиннее 12 часов», сохранённое значение не меняется.

### UC-10
**Тип:** граница · **Роль:** пользователь · **Требования:** R-16, R-17, N-13
**Предусловия:** у пользователя 4 удара, активные задачи, диалог боя, место в рейтинге.
**Шаги:**
1. Нажимает «Удалить аккаунт», подтверждает.
2. Видит «4 удара сгорят», подтверждает окончательно.
**Результат:** профиль, задачи, лента, диалоги, уважение, побеждённость удалены; в рейтинге его нет; сообщения по расписанию не приходят; записи платежей и признак «уже был» сохранены.

### UC-11
**Тип:** права · **Роль:** пользователь, владелец · **Требования:** R-17, N-10, N-13
**Шаги:**
1. Пользователь пытается изменить настройки или удалить аккаунт другого пользователя, подменив данные запроса.
2. Владелец открывает данные удалённого пользователя.
**Результат:** запрос отклонён, чужие данные не меняются; владелец видит только записи платежей удалённого пользователя без задач и диалогов.

### UC-12
**Тип:** пустое состояние · **Роль:** пользователь · **Требования:** R-16
**Предусловия:** у пользователя нет задач и 0 ударов.
**Шаги:**
1. Нажимает «Удалить аккаунт».
**Результат:** второе подтверждение без строки о сгорающих ударах; после подтверждения аккаунт удалён.

# F-14 Шеринг

**Кто:** пользователь · **Суть:** пользователь отправляет в чат Telegram карточку с фразой персонажа после «Готово», провала или боя, без личных данных · [← ТЗ](../spec.md)

## Требования
| id | требование | критерий приёмки | сценарии |
|---|---|---|---|
| R-118 | Система по «Поделиться» на экранах «Готово», «Провал» и «Бой» создаёт карточку-изображение с фразой персонажа, ролью, для «Боя» — степенью победы, и ссылкой на бота без реферальной метки, и открывает выбор чата Telegram для отправки (A-51). На карточку идёт только фраза пула: для «Готово» и «Провал» — фраза с экрана, для «Боя» — onBreak, если персонаж сломлен, иначе onBattleStart; ответ актёра на карточку не попадает (A-70) | Когда пользователь нажимает «Поделиться» после слома, тогда видит карточку с фразой onBreak, степенью победы 100 и окно выбора чата | [UC-67](F-12-battle-turn.md#uc-67), [UC-78](#uc-78), [UC-79](#uc-79), [UC-82](#uc-82) |
| R-119 | Система не помещает на карточку имя, username пользователя и название задачи (A-51); в фразе на карточке `{task}` заменяется словом «задачу», а `{name}` — словом «сынок» или «дочка» по полу пользователя (A-70) | Когда пользователь делится провалом задачи «уволиться с работы», тогда на карточке нет этого названия и имени пользователя; когда фраза провала содержит `{task}` и `{name}`, тогда на карточке стоят «задачу» и «сынок» (или «дочка») | [UC-78](#uc-78), [UC-79](#uc-79), [UC-81](#uc-81) |
| R-120 | Система при ошибке создания карточки показывает сообщение и кнопку повтора | Когда создание карточки не удалось, тогда показано «Не получилось, ещё раз?» с кнопкой повтора | [UC-80](#uc-80) |

## Сценарии
Типы: основной, альтернативный, ошибка, граница, права, пустое состояние. Тип, который не применим, записан явно с причиной.

### UC-78
**Тип:** основной · **Роль:** пользователь · **Требования:** R-118, R-119
**Предусловия:** персонаж только что сломлен.
**Шаги:**
1. Нажимает «Поделиться».
**Результат:** карточка-изображение с фразой onBreak, ролью, степенью победы 100 и ссылкой на бота; открыт выбор чата Telegram.

### UC-79
**Тип:** альтернативный · **Роль:** пользователь · **Требования:** R-118, R-119
**Шаги:**
1. Нажимает «Поделиться» на экране «Готово», затем на экране «Провал».
**Результат:** карточки с фразой onSuccess и с фразой провала и штампом; без имени, username и названия задачи.

### UC-80
**Тип:** ошибка · **Роль:** пользователь · **Требования:** R-120
**Что идёт не так:** карточку не удалось создать.
**Поведение:** «Не получилось, ещё раз?» и кнопка повтора; ничего не отправлено.

### UC-81
**Тип:** граница · **Роль:** пользователь · **Требования:** R-119
**Шаги:**
1. Делится провалом задачи «уволиться с работы» с названием длиной 120 символов; фраза провала на экране — «{name}, ты опять провалил {task}».
**Результат:** на карточке «Сынок, ты опять провалил задачу» (A-70); нет названия задачи и данных пользователя, только фраза персонажа и ссылка.

### UC-82
**Тип:** пустое состояние · **Роль:** пользователь · **Требования:** R-118
**Предусловия:** бой с текущей ролью открыт впервые, ходов не было.
**Шаги:**
1. Нажимает «Поделиться» на странице «Бой».
**Результат:** карточка с фразой onBattleStart и степенью победы 0.

### Права
Не применимо: карточка не содержит данных пользователя (R-119), ссылка ведёт в бота без привязки к отправителю, любой получатель видит одно и то же.
